# Browser Tab Mockup

A browser-interface mockup built using HTML, CSS, and JavaScript. The project demonstrates multiple tabs, URL navigation, embedded webpage display, and basic browser navigation controls.

## Features

- **Multiple tabs:** Create and switch between browser tabs.
- **URL navigation:** Enter a URL to load a page inside an iframe.
- **Back navigation:** Return to a previously visited page within a tab.
- **Forward navigation:** Move forward through the recorded navigation history.
- **Refresh:** Reload the currently entered page.
- **Responsive styling:** Adjust the URL input field for different screen widths.
- **Independent tab state:** Maintain separate navigation history for each tab.

## Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Defines the browser interface and tab content structure. |
| CSS3 | Styles the tabs, navigation controls, layout, and responsive elements. |
| JavaScript | Handles tab creation, tab switching, URL loading, and navigation history. |
| HTML iframe | Displays webpages within each tab. |

## How It Works

1. The application creates an initial tab when the page loads.
2. Users can create additional tabs using the **+** button.
3. Selecting a tab displays its associated content area.
4. Entering a URL and pressing Enter loads the address in the tab's iframe.
5. Back, forward, and refresh controls update the displayed page.
6. Each tab maintains its own navigation history.
